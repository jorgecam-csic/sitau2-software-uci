# bootimage

Plantillas portables de los dos productos de entrega. Las rutas se resuelven desde el workspace al empaquetar.

## Archivos

| Archivo | Función |
| --- | --- |
| [cpu0-boot.bif.in](cpu0-boot.bif.in) | Plantilla de arranque: FSBL + bitstream de UCI + CPU0. |
| [cpu1-network.bif.in](cpu1-network.bif.in) | Plantilla de carga por red: solo CPU1, sin FSBL ni bitstream. |
