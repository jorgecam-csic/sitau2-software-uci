# MK32

Paquetes de hardware MK32 recibidos de proyectos externos. No son entradas de compilación del software UCI ni se incorporan a su imagen de arranque.

## Versiones

- [0.0.0](0.0.0/README.md): conjunto inicial seleccionado por el usuario de la raíz del BIN heredado.

Cada versión conserva juntos BIN, BIT y LTX, con manifiesto y SHA-256. Añadir una nueva carpeta para futuras entregas; no sobrescribir una versión existente.
